# 01 — Hello, World no Docker

## Objetivo

Executar seu primeiro container Docker e entender o que acontece.

## Tarefas

1. Rode o container `hello-world` do Docker.
2. Analise a saída. O que ela diz sobre o ciclo de vida de um container?
3. Descubra:
   - Como listar containers que já rodaram? E só os rodando?
   - Como remover um container que já parou?
   - Existe container rodando agora? Por que sim ou por que não?
4. Responda com suas palavras: **qual a diferença entre uma imagem e um container?**

## Perguntas extras

- O que `docker ps -a` mostra que `docker ps` não mostra?
- O que acontece se você rodar `docker run hello-world` duas vezes? Cria dois containers ou reusa o mesmo?
- Dá pra "entrar" no container hello-world depois que ele termina? Por que?
