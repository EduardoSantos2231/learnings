# Docker como competencia complementar

Docker acompanha os marcos do Go Backend. Nao abra uma fila de estudos separada:
containerize, teste e opere o codigo produzido na espinha dorsal.

## Rotacao

| Marco Go | Checkpoint |
|----------|------------|
| Diagnostico | build, run, logs e porta |
| API HTTP | healthcheck e encerramento |
| Concorrencia | sinais e PID 1 |
| Cache | multi-stage e imagem pequena |
| Capstone | Compose, rede e volume se necessario |

## Pronto quando

- O comando de build e reproducivel.
- O servico responde dentro do container.
- O aluno consegue explicar o processo principal e o estado do container.

Use `tracking session` para a proxima tarefa; Docker aparece como parte do
criterio operacional do desafio Go quando o marco exigir.
