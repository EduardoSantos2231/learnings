# C3 — Binary Search Tree

> Implementacao | 60 min | Go stdlib

## Objetivo

Implemente uma BST com busca, insercao e remocao dos tres casos.

## Faca

1. Implemente `Insert` e `Search`.
2. Implemente `Delete` para folha, um filho e dois filhos.
3. Use o sucessor inorder no caso de dois filhos.
4. Exponha uma travessia inorder para testar a ordenacao.

## Restricoes

- Mantenha a propriedade da BST.
- Nao converta a arvore para slice para remover.

## Pronto quando

- A travessia inorder permanece ordenada.
- Os tres casos de remocao passam.
- Busca em arvore vazia e segura.

## Responda

- Qual no substitui o removido com dois filhos?
- Qual e o pior caso de complexidade?
