# C1 — Stack e Queue

> Explicacao pratica | 45 min | Go stdlib

## Objetivo

Compare stack e queue implementando as operacoes essenciais e explicando o uso correto.

## Faca

1. Implemente `Push/Pop` para stack.
2. Implemente `Enqueue/Dequeue` para queue.
3. Proteja cada estrutura para uso concorrente.
4. Escreva um caso de uso para cada uma.

## Pronto quando

- Estruturas vazias retornam resultado seguro.
- Testes verificam LIFO e FIFO.
- A explicacao identifica o custo das operacoes.

## Responda

- Qual estrutura voce usaria para undo?
- Como evitar referencias mantidas por uma queue?
