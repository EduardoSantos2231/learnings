# A3 — Linked List

> Implementacao | 60 min | Go stdlib

## Objetivo

Implemente uma lista simplesmente ligada com operacoes seguras em lista vazia.

## Faca

1. Implemente `Push`, `Remove` e `Find`.
2. Implemente `Reverse` in-place.
3. Retorne resultado claro para item ausente.
4. Cubra lista vazia, um item e varios itens.

## Restricoes

- Nao converta a lista para slice.
- `Reverse` deve usar memoria auxiliar O(1).

## Pronto quando

- A ordem dos itens esta correta depois de cada operacao.
- Nenhum acesso a `nil` causa panic.
- `go test ./...` passa.

## Responda

- Qual ponteiro precisa ser salvo antes de avancar?
- Qual e a complexidade de cada operacao?

> Confianca: [1-5]
